4. FLUXO DE RETRY (FALHA DE REDE)
═══════════════════════════════════════════════════════════════════════════════

┌──────────────────────────────────────────┐
│  fetch('/api/booking')                   │
│  (Network error!)                        │
└────────┬─────────────────────────────────┘
         │
         ▼
┌──────────────────────────────────────────┐
│  fetchWithRetry detecta erro             │
│  • Erro: network timeout                 │
│  • Max retries: 3                        │
│  • Backoff: 1000ms                       │
└────────┬─────────────────────────────────┘
         │
         ▼
┌──────────────────────────────────────────┐
│  Tentativa 1                             │
│  fetch('/api/booking')                   │
│  ✗ ERRO                                  │
│                                           │
│  Aguarda 1000ms                          │
└────────┬─────────────────────────────────┘
         │
         ▼
┌──────────────────────────────────────────┐
│  Tentativa 2                             │
│  fetch('/api/booking')                   │
│  ✗ ERRO                                  │
│                                           │
│  Aguarda 1000ms                          │
└────────┬─────────────────────────────────┘
         │
         ▼
┌──────────────────────────────────────────┐
│  Tentativa 3                             │
│  fetch('/api/booking')                   │
│  ✓ SUCESSO!                              │
│                                           │
│  Retorna dados                           │
└────────┬─────────────────────────────────┘
         │
         ▼
┌──────────────────────────────────────────┐
│  Cliente/Parceiro nunca notou o erro!    │
│  Operação continua normalmente           │
└──────────────────────────────────────────┘

│ Ou (se todas 3 falharem):
│
│ ▼
│ ┌──────────────────────────────────────────┐
│ │  throw Error("Network failed after 3...")│
│ │                                           │
│ │  Mostra toast:                           │
│ │  ✗ "Erro de conexão. Tente novamente."   │
│ │                                           │
│ │  Usuário notado do erro                  │
│ └──────────────────────────────────────────┘

       │
       ▼
┌──────────────────────────────┐
│ 🗄 Database                  │
│ bookings.insert({            │
│   status: 'pending_...'      │
│ })                           │
└──────┬───────────────────────┘
       │
       ▼
┌──────────────────────────────┐
│ 📱 Cliente vê:              │
│ useBookingPolling inicia    │
│ Status: "pending_assignment" │
│ "Aguardando confirmação..."  │
└──────┬───────────────────────┘
       │
       ▼ (polling a cada 5s)
       │
       ▼ (backend notifica parceiro)
       │
┌──────────────────────────────┐
│ 👨‍💼 Parceiro vê:            │
│ usePartnerDashboardPolling   │
│ detecta novo booking         │
│ 🔔 Toast: "Novo booking!"    │
└──────┬───────────────────────┘
       │
       ▼
┌──────────────────────────────┐
│ Parceiro clica "Aceitar"     │
│ PUT /api/bookings/accept     │
│                              │
│ 🗄 bookings.update({         │
│   status: 'confirmed'        │
│ })                           │
└──────┬───────────────────────┘
       │
       ▼ (polling cliente detecta)
       │
┌──────────────────────────────┐
│ 📱 Cliente vê:              │
│ Status mudou!               │
│ 🎉 Toast: "Confirmado!"     │
│                              │
│ Cliente FELIZ ✓              │
└──────────────────────────────┘
